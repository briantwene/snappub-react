# SnapPub

Discover and download stunning wallpapers from Reddit.

## Description

SnapPub is a web application that curates and delivers high-quality wallpapers from various subreddits. Whether you're looking for breathtaking landscapes, artistic illustrations, or minimalist designs, SnapPub provides a seamless experience for finding and downloading the perfect wallpaper for your device.

## Current Features and Changes

- 🔒 **User Authentication with Reddit**: Users can now authenticate with their Reddit accounts. Due to changes to the API last year, it was only possible to fetch the first few images or be rate-limited quite a bit. No more rate limits, yay!
- 🛠️ **Migrating Codebase to TypeScript**: It's 2024, man! The codebase has been migrated to TypeScript for better type safety and developer experience. TypeScript, here I come!

## Upcoming Features

- 🎨 **Switching to Sass Modules + Redesign**: Switching over to Sass modules for a complete redesign of the user interface. Enjoy the fresh new look!
